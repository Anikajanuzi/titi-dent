# TITI DENT website

Open `index.html` directly in a browser to view the website. No Node.js or terminal is required.

## Pages

- `index.html` — Home
- `laboratory.html` — Laboratory
- `patients.html` — Patients
- `prosthetics.html` — Prosthetics
- `pricing.html` — Pricing
- `contact.html` — Contact

## Adding pricing images

Put images in the `assets/prices` folder using these file names. JPG is expected; until an image exists, the TITI DENT logo is shown automatically.

`silicone.jpg`, `silicone-vita.jpg`, `acrylic.jpg`, `acrylic-vita.jpg`, `reline.jpg`, `repair.jpg`, `zirconia.jpg`, `metal-porcelain.jpg`, `implant.jpg`, `vizil.jpg`, `retainer.jpg`, `bruxism.jpg`

## Deploying on Vercel

Create a new GitHub repository containing this project folder, then import that repository on Vercel. It is configured as a static site; no build command is needed.
